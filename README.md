# ESP32 วัดระดับน้ำในถัง 💧

รู้ว่าน้ำในถังเหลือกี่เปอร์เซ็นต์จากมือถือ น้ำต่ำกว่า 20% ส่งแจ้งเตือนเข้า Discord ทันที ไม่ต้องปีนขึ้นไปดู

จากคลิป **K iTech Review** (TikTok) · **Kham iTech Lab** (YouTube / Facebook)

## ของที่ใช้

| ชิ้น | หมายเหตุ |
|---|---|
| บอร์ด ESP32 | รุ่นไหนก็ได้ |
| เซนเซอร์อัลตราโซนิกกันน้ำ JSN-SR04T | หัววัดกันน้ำ ทนไอน้ำในถังได้ดีกว่า HC-SR04 |
| ตัวต้านทาน 1k และ 2k | แบ่งแรงดันขา ECHO |

## ต่อสาย

| JSN-SR04T | ต่อเข้า |
|---|---|
| 5V | 5V / VIN ของ ESP32 |
| GND | GND |
| TRIG | GPIO 5 |
| ECHO | ผ่านตัวต้านทาน 1k เข้า GPIO 18 แล้วต่อตัวต้านทาน 2k จาก GPIO 18 ลง GND |

ขา ECHO ส่งออกมา 5V แต่ ESP32 รับได้แค่ 3.3V ตัวต้านทานสองตัวนี้แบ่งให้เหลือราว 3.3V

## ติดหัววัด

- ติดหัววัดไว้ใต้ฝาถัง หันลงตรง ๆ ไม่ให้เอียง และไม่ให้เสียงไปชนท่อหรือลูกลอย
- JSN-SR04T วัดระยะใกล้กว่าราว 25 ซม. ไม่ได้ ให้หัววัดอยู่สูงกว่าระดับน้ำเต็มอย่างน้อย 25 ซม.

## ตั้งค่า

1. เปิด Arduino IDE ติดตั้งบอร์ด ESP32 (Boards Manager → esp32 by Espressif) ไม่ต้องลงไลบรารีเพิ่ม
2. เปิดไฟล์ `water_tank_level/water_tank_level.ino`
3. ใส่ `WIFI_SSID`, `WIFI_PASS` และวางลิงก์ Webhook ใน `WEBHOOK_URL`
4. วัดถังแล้วใส่ 2 ค่า
   - `TANK_HEIGHT_CM` ระยะจากหน้าหัววัด ถึงก้นถัง
   - `FULL_GAP_CM` ระยะจากหน้าหัววัด ถึงผิวน้ำตอนเต็ม
5. อัปโหลด แล้วเปิด Serial Monitor ที่ 115200 จะเห็นระยะกับเปอร์เซ็นต์ทุก 5 วินาที

### สร้างลิงก์ Webhook

Discord → ตั้งค่าห้องแชต (Edit Channel) → **Integrations** → **Webhooks** → **New Webhook** → **Copy Webhook URL**

⚠️ ห้ามแชร์ลิงก์นี้ให้ใคร ถ้าเผลอหลุด ให้ลบ Webhook แล้วสร้างใหม่

## ดูระดับน้ำ

เปิด IP ที่ขึ้นใน Serial Monitor หรือ `http://watertank.local` ในมือถือ (ต้องต่อ Wi-Fi บ้านเดียวกัน) จะเห็นรูปถังกับเปอร์เซ็นต์น้ำ อัปเดตเองทุก 5 วินาที

## การแจ้งเตือน

- น้ำต่ำกว่า `LOW_ALERT_PCT` (20%) ส่งเตือน 1 ครั้ง
- น้ำกลับมาเกิน `REARM_PCT` (30%) ส่งข้อความว่าน้ำกลับมาแล้ว และพร้อมเตือนรอบใหม่
- เว้นช่วงไว้แบบนี้ เพื่อไม่ให้เตือนรัว ๆ ตอนน้ำกระเพื่อมอยู่แถว 20%

## ปัญหาที่เจอบ่อย

- **ขึ้น "วัดไม่ได้"**: เช็กสาย TRIG/ECHO สลับกันไหม และหัววัดเสียบแน่นไหม
- **ค่ากระโดด**: หัววัดเอียง หรือเสียงไปชนผนังถังหรือท่อ ลองขยับไปกลางฝาถัง
- **น้ำเต็มแต่ขึ้นไม่ถึง 100%**: วัด `FULL_GAP_CM` ใหม่ให้ตรงกับระยะจริงตอนน้ำเต็ม
